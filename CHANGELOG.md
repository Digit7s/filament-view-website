## [1.0.0] - 2026-10-01

### Added

- Initial public release with Filament 5 support.
- Native `Visit Website` action in the Filament panel topbar.
- Zero-configuration defaults using the Laravel application root URL.
- Configurable URL, label, icon, and tooltip.
- Static and closure-based configuration values.
- New-tab and same-tab navigation support.
- Conditional visibility using booleans or closures.
- Safe handling of blank URLs by omitting the action.
- Native Filament styling with dark mode support.
- Panel-scoped registration through the Filament plugin API.
